# Warrior Codex Player

The app for joining your GM's Warrior Codex game. This page holds only its releases: no game code and no world.

**First time?** Open [Releases](../../releases/latest), download `Warrior_Codex_Player_Setup.exe` and double-click it. It installs just for you, in about a minute, and asks for the link your GM sent.

**After that** the app updates itself: it fetches a new version in the background and puts it in when you close it.

If Windows says "Windows protected your PC", click **More info**, then **Run anyway** (the app isn't signed; that's all it means).
